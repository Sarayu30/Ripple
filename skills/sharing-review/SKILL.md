# Sharing review

Inspect transcript or caption, and analysis if a visual moment affects usefulness.
Identify who this persona would send the content to and why, or state that there
is no credible recipient. Do not invent an existing social graph or actual share.
Distinguish private saving, public sharing, comments, and passive enjoyment.
Consider reputational risk or missing context as well as usefulness. Recommend
one edit that makes the useful idea easier to understand without promising reach.
Score from this viewer's own motivation; never copy a cohort-wide assumption.
