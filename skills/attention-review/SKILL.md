# Attention review

Read transcript or caption with inspect_evidence; read analysis if visual evidence exists.
Judge the opening against this viewer's motivation and viewing context. Separate
what the content actually communicates from the creator's intended message.
Identify one point of confusion or effort, and one specific edit that reduces it.
If only text or sampled frames exist, mark timing and motion judgments uncertain.
Give honest stop/finish decisions, emotion, objection, and intent scores. A clear
message can still be irrelevant to this viewer. Do not equate liking with sharing.
